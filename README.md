# Kurisu-companion
This is a Makise Kurisu Companion, Made it out of boredom but planning to make it a whole windows tool manager and for linux aswell. "it is on beta"
 Kurisu Companion is a desktop pet app. Kurisu floats on your screen with no window frame, always on top. Click her to change her pose, drag her to move her, and scroll to resize her. She remembers her position and size between runs.

The Future Gadget Lab pin on her shoulder is the tool menu. Click it and choose Storage Manager a small search for files n stuff.

The first time you start the app, it scans your drives in the background and saves a list of every file and folder name. Searches read from that list, so results show up as you type, with no waiting for a disk scan. The list refreshes itself once a day, and you can refresh it by hand from the
But this is the prototype, Working on making makises whole personalilty into a AI bot that talks back to you, Kinda like the game/anime. She could fix up code for you, Give you advice on your coding or workspace, Fix any major or minor computer issues "Not hardware" ofc.
